# Brain Tumor Analysis Using Deep Learning

## Project Overview
This project aims to analyze brain MRI images using deep learning techniques for brain tumor classification and segmentation.

## Dataset
BRISC 2025 brain MRI dataset, containing four classification categories:
- Glioma
- Meningioma
- Pituitary
- No Tumor

## Work Completed
- Dataset loading and preprocessing
- Baseline CNN and class-weighted CNN
- Transfer learning using MobileNetV2, EfficientNetB0, DenseNet121, ResNet50, and InceptionV3
- U-Net-based tumor-region segmentation
- Initial model evaluation and comparison

## Planned Work
- Further segmentation validation
- Tumor-region area estimation
- Grad-CAM explainability
- Integration into a unified application

## Tools and Technologies
Python, Google Colab, TensorFlow/Keras, NumPy, Matplotlib, and scikit-learn.
